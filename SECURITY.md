# Security

Report security problems privately through the repository owner's GitHub contact route before posting working exploit details. Do not attach browser databases, tokens, full machine reports or personal file lists to public issues.

Optimus is a local administrative utility. Actions can uninstall applications, remove selected packages, delete cache/privacy data and change process allocations. Default configuration does not remove applications or change Codex priority.

Code edited in Sandbox is user-authored code, not isolated untrusted code. Restarting that source runs it with the current Windows permissions. Keep administrator sessions limited to the operations that need them.

The application does not automatically weaken Windows Defender, Controlled Folder Access, signing policy, firewall protection or UAC. Unsupported vendor/OS operations are reported rather than silently forced through unrelated settings.
